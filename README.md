# spatial-microglia-threshold
# Spatial Microglia Threshold Analysis

This repository contains the analysis pipeline for the paper:

**"A Spatial Hazard Model Reveals a 25 μm Transcriptomic Event Horizon for Plaque‑Associated Microglial Activation in Alzheimer’s Disease"**

Author: Benjamin Otuya

The main notebook (`spatial_microglia_threshold_pipeline.ipynb`) performs the GMM thresholding, XGBoost classification, SHAP analysis, and spatial discontinuity testing on the SEA‑AD MERFISH dataset.
